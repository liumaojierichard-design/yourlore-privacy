# yourlore-privacy

“你探 / YourLore · Urban Legend Pilgrimage” 隐私政策静态页面。

本仓库通过 GitHub Pages 发布为公开网址，供 App Store Connect、Google Play 及中国大陆各安卓应用商店填写「隐私政策 URL」使用。

## 文件结构

| 文件 | 用途 |
|---|---|
| `index.html` | 选版落地页（根网址直接打开） |
| `privacy.html` | 海外版（英文）—— App Store / Google Play 填写此文件的网址 |
| `privacy-cn.html` | 大陆版（简体中文）—— 微信小程序及国内安卓商店适用 |

## 公开网址

- 落地页：`https://liumaojierichard-design.github.io/yourlore-privacy/`
- 海外版政策：`https://liumaojierichard-design.github.io/yourlore-privacy/privacy.html`

> 发布前务必先替换 `privacy.html` / `privacy-cn.html` 中的占位（`[PRIVACY EMAIL]` / `[OFFICE ADDRESS]` / `[REGISTRATION NUMBER]` / `[VERSION]` / `[EFFECTIVE DATE]`），否则审核会看到方括号占位。
